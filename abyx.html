ABYX: A Controller-Based Type System

Role
Concept, type system, specimen and web app
Course
Master of Communication Design, RMIT
Year
2025
Type
Solo project

ABYX is a speculative type system for accessible communication. It maps the 26 letters of the Latin alphabet to three-button combinations using only the A, B, X and Y buttons of a game controller, so that someone with limited hand movement can type with a thumb.

The Idea

Game controllers are already designed for comfort, repetition and many kinds of hand movement. ABYX borrows that logic to make a new kind of alphabet: one that is tactile and digital, for people who face barriers with keyboards and touchscreens.

Each letter is a character and also a gesture: a short sequence of presses that can be made with one thumb or with adaptive hardware.

How It Works

Four buttons pressed three times give 64 possible combinations, more than enough for 26 letters. The letters are assigned in a fixed, countable order, so the system can be learned as a pattern and not memorised one letter at a time.

Why It Matters

ABYX is more than a font. It is a communication tool that imagines game interfaces going beyond entertainment and becoming platforms for equity, creativity and voice. It invites designers, developers and accessibility advocates to rethink how an alphabet can be encoded: by touch and interaction as well as by sight.
