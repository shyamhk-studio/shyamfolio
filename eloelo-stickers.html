Bollywood Stickers in Comments

The brief was a set of stickers that would help viewers react to streamers in a livelier way, right in the comments of a live stream.

I chose Bollywood as the theme, because it was the most relatable subject for the audience, and illustrated five iconic movie moments and dialogues as sticker reactions.

The Sticker Set

Each Reaction

Every sticker pairs a caricature with a line people already quote, so it reads instantly at comment size.
